# Project Spec: การเพิ่มระบบอัซการ (Athkar) ใน NoorPath

## 1. เป้าหมาย (Objective)
เพิ่มฟีเจอร์ **อัซการ (Athkar)** ประจำวันลงในเว็บแอปพลิเคชัน **NoorPath** (`mkrissada/NoorPath`) โดยอ้างอิงเนื้อหาจากหนังสือ *ฮิศนุล มุสลิม (Hisn al-Muslim)* และ *อัซการยามเช้า-ยามเย็น* ให้สามารถใช้งานแบบ **Offline-first บน iPad** ได้อย่างสมบูรณ์

---

## 2. แหล่งข้อมูลอ้างอิง (Data Sources)
1. **โครงสร้างและข้อความหลัก:** `https://salafilibary.vercel.app/`
2. **หนังสืออ้างอิงฉบับเต็ม (ฮิศนุล มุสลิม ภาษาไทย):** `https://d1.islamhouse.com/data/th/ih_books/single/th_hisnu_muslim.pdf`
3. **หนังสืออัซการยามเช้า-ยามเย็น (ภาษาไทย):** `https://d1.islamhouse.com/data/th/ih_books/th_athkar_assabah_walmasaa.pdf`

---

## 3. ขั้นตอนการดำเนินงานสำหรับ AI Agent (agy)

### ขั้นตอนที่ 1: การเตรียมข้อมูล (`athkar.json`)
- ดึงข้อมูลหมวดหมู่อัซการจาก `https://salafilibary.vercel.app/` (เน้นหมวด **อัซการยามเช้า**, **อัซการยามเย็น**, **อัซการหลังละหมาด**, และ **อัซการก่อนนอน/ตื่นนอน** เป็นลำดับแรก)
- ตรวจสอบความถูกต้องของสระภาษาอาหรับ (Tashkeel) และคำแปลภาษาไทยเทียบกับไฟล์ PDF ต้นฉบับจาก IslamHouse
- สร้างไฟล์ใหม่ชื่อ `athkar.json` ไว้ที่ Root Directory ของโปรเจกต์ตามโครงสร้าง (Schema) ด้านล่างนี้:

### ขั้นตอนที่ 2: การออกแบบและพัฒนา UI ใน `index.html`
เพิ่มเมนูหรือแท็บ **"อัซการ (Athkar)"** ในไฟล์ `index.html` โดยคำนึงถึง UX/UI สำหรับการใช้งานบนหน้าจอ **iPad (Touch-friendly)**:

1. **ตัวเลือกหมวดหมู่ (Category Selector):**
   - แสดงปุ่มหรือแถบเลือกหมวดหมู่อัซการ (เช่น ยามเช้า, ยามเย็น, หลังละหมาด, ก่อนนอน) ที่กดสลับได้ง่าย
2. **การ์ดแสดงบทอัซการและการนับรอบ (Tap-to-Count Card):**
   - แสดงตัวบท **ภาษาอาหรับ** (จัดชิดขวา `dir="rtl"` ใช้ฟอนต์ที่อ่านสระชัดเจน)
   - แสดง **คำอ่านภาษาไทย (Transliteration)** และ **คำแปลภาษาไทย**
   - มีปุ่ม/พื้นที่ **ตัวนับจำนวนรอบ (`repeat`)**: เมื่อผู้ใช้แตะที่ตัวนับหรือการ์ด ตัวเลขจะลดลงทีละ 1 (เช่น `3` -> `2` -> `1` -> `0`) เมื่อครบ `0` ให้เปลี่ยนสถานะการ์ดเป็น "เสร็จสิ้น" (เช่น เปลี่ยนสีขอบหรือลดความทึบแสงลงเล็กน้อย) และมีปุ่ม **Reset** เพื่อเริ่มนับใหม่ทั้งหมดได้
3. **แถบเครื่องมือช่วยอ่าน (Reader Controls):**
   - **ปุ่มปรับขนาดตัวอักษรอาหรับ (A- / A+):** บันทึกค่าขนาดฟอนต์ไว้ใน `localStorage`
   - **ปุ่มเปิด/ปิด (Toggle):** สำหรับซ่อนหรือแสดง *คำอ่านภาษาไทย* และ *คำแปล* เพื่อให้ผู้ที่อ่านอาหรับคล่องสามารถอ่านเฉพาะตัวบทอาหรับล้วนได้

---

### ขั้นตอนที่ 3: อัปเดต Service Worker (`sw.js`) เพื่อรองรับ Offline
1. เปิดไฟล์ `sw.js` และเพิ่ม `'./athkar.json'` เข้าไปในอาร์เรย์ของไฟล์ที่ต้องการ Pre-cache (เช่น `urlsToCache` หรือ `ASSETS`)
2. อัปเดตชื่อ/เลขเวอร์ชันของ Cache (เช่น `CACHE_NAME = 'noorpath-v2'`) เพื่อให้เบราว์เซอร์บน iPad ดึงไฟล์ `index.html` ฉบับอัปเดตและ `athkar.json` ไปเก็บในแคชทันทีที่เชื่อมต่ออินเทอร์เน็ต
3. ตรวจสอบให้แน่ใจว่าเมื่อเปิดใช้งานในโหมดเครื่องบิน (Airplane Mode) หน้าอัซการสามารถโหลดข้อมูลจาก `athkar.json` ขึ้นมาแสดงผลได้โดยไม่เกิด Error

## 4. เกณฑ์การตรวจสอบความสมบูรณ์ (Acceptance Criteria)
- [ ] มีไฟล์ `athkar.json` ที่โครงสร้างถูกต้อง ไม่เกิด Syntax Error และสระภาษาอาหรับแสดงผลครบถ้วน
- [ ] หน้า `index.html` แสดงผลหมวดหมู่อัซการได้สวยงาม รองรับการแสดงผลทั้งแนวตั้งและแนวนอนบน iPad
- [ ] ระบบ Tap-to-Count นับถอยหลังได้แม่นยำ และมีปุ่มรีเซ็ตจำนวนรอบของหมวดนั้นๆ
- [ ] ปุ่มปรับขนาดฟอนต์อาหรับและปุ่มซ่อน/แสดงคำแปลทำงานได้จริง
- [ ] ทดสอบปิดอินเทอร์เน็ตบนเบราว์เซอร์แล้ว สามารถเปิดหน้าอัซการและใช้งานได้เต็มรูปแบบ 100%
