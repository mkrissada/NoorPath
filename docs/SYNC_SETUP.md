# คู่มือตั้งค่าซิงก์ข้อมูลส่วนตัวด้วย Google Sheets (Apps Script)

ระบบซิงก์ของ NoorPath ใช้ Google Sheet ส่วนตัวของคุณเป็นฐานข้อมูลกลาง ทำให้สามารถเปิดอ่านและซิงก์ความก้าวหน้า (อายะฮ์ที่อ่านแล้ว, สถานะท่องจำ Hifz, หะดีษที่อ่านแล้ว, บุ๊กมาร์ก, รอบคอตัม, และหน้ามุศหัฟล่าสุด) ข้าม iPad, iPhone หรือคอมพิวเตอร์ได้ฟรีและเป็นส่วนตัว

---

## ขั้นตอนที่ 1: สร้าง Google Sheet และวางสคริปต์

1. เปิด [Google Sheets](https://sheets.google.com) ด้วยบัญชี Google ของคุณ แล้วกดสร้าง **สเปรดชีตใหม่ (Blank spreadsheet)** ตั้งชื่อว่า `NoorPath Sync`
2. ที่เมนูด้านบน กด **ส่วนขยาย (Extensions)** → **Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `apps-script/Code.gs` (หรือกดปุ่ม **"คัดลอกโค้ด Apps Script"** ในหน้าตั้งค่าของแอป NoorPath) มาวางแทนที่
4. กดไอคอนรูปแผ่นดิสก์ (**Save project**)

## ขั้นตอนที่ 2: ตั้งค่ารหัสลับ (Token)

1. ในหน้า Apps Script กดไอคอนรูปเฟืองด้านซ้าย (**Project Settings / การตั้งค่าโปรเจกต์**)
2. เลื่อนลงไปที่ส่วน **Script Properties** กด **Add script property**
   - **Property**: `NOORPATH_TOKEN`
   - **Value**: ใส่รหัสลับที่สุ่มจากปุ่มในหน้าตั้งค่าของแอป NoorPath (หรือพิมพ์รหัสที่คาดเดายากด้วยตนเอง)
3. กด **Save script properties**

> *(ทางเลือก)* หากไม่ถนัดตั้ง Script Properties สามารถนำรหัสลับไปใส่ในตัวแปร `FALLBACK_TOKEN = 'รหัสของคุณ';` บรรทัดบนสุดของ `Code.gs` แทนได้

## ขั้นตอนที่ 3: Deploy เป็น Web App

1. กดปุ่มสีน้ำเงินมุมขวาบน **Deploy** → **New deployment**
2. ตรงไอคอนฟันเฟืองข้าง Select type เลือก **Web app**
3. ตั้งค่าดังนี้:
   - **Description**: `NoorPath Sync v1`
   - **Execute as**: **Me** (บัญชีของคุณ)
   - **Who has access**: **Anyone** *(ปลอดภัยเพราะทุกคำขอต้องแนบ Token ที่ตรงกับ `NOORPATH_TOKEN`)*
4. กด **Deploy**
5. หาก Google ขอสิทธิ์การเข้าถึงครั้งแรก ให้กด **Authorize access** → เลือกบัญชี Google → **Advanced** → **Go to ... (unsafe)** → **Allow**
6. คัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`) เก็บไว้

## ขั้นตอนที่ 4: เชื่อมต่อบน iPad และอุปกรณ์อื่น

1. เปิดแอป NoorPath ไปที่แท็บ **ตั้งค่า & Offline** → หัวข้อ **ซิงก์ข้อมูลข้ามอุปกรณ์ (Google Sheets)**
2. เปิดใช้งานสวิตช์ซิงก์ แล้วกรอก:
   - **Web App URL**: URL ที่ได้จากขั้นตอนที่ 3
   - **Token ลับ**: รหัสเดียวกับที่ตั้งไว้ใน `NOORPATH_TOKEN`
   - **ชื่ออุปกรณ์**: เช่น `iPad` หรือ `iPhone`
3. กด **ทดสอบการเชื่อมต่อ** — หากขึ้นว่าเชื่อมต่อสำเร็จ ให้กด **ซิงก์ตอนนี้**
4. ทำซ้ำขั้นตอนที่ 4 บนอุปกรณ์อื่น โดยใช้ Web App URL และ Token เดียวกัน

---

## การดูแลรักษาและการอัปเดตโค้ด Apps Script

- ใน Google Sheet จะมี 2 แท็บเกิดขึ้นอัตโนมัติ:
  - **`สรุปภาพรวม`**: ตารางสรุปจำนวนอายะฮ์ที่อ่าน/จำได้ หะดีษ บุ๊กมาร์ก และเวลาซิงก์ล่าสุด
  - **`records`**: ข้อมูลดิบรายรายการสำหรับซิงก์แบบ Last-Write-Wins (ไม่ควรแก้ไขแถวในแท็บนี้ด้วยมือ)
- ข้อมูล URL และ Token จะถูกเก็บใน **เครื่องนั้นๆ เท่านั้น (`localStorage`)** และไม่ถูกส่งออกในไฟล์สำรอง `.json` เพื่อความปลอดภัย
